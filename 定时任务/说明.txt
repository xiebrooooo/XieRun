定时跑步（Windows 计划任务）
================================================================================

这里只有两个文件，所有包共用：

  定时跑步.cmd      实际执行："<运动规划.exe>" run --dist .. --pace ..
  注册每日任务.ps1  把上面这条注册成「每天固定时刻」的计划任务

日志写在脚本旁边的 logs\yyyyMMdd.log，一次运行一段：

  ===== 2026-10-15 07:32:11 start: --dist 2.0 --pace 390 --time 07:32 =====
  （exe 的完整输出）
  ----- 2026-10-15 07:33:40 exit 0 -----


一、一次性准备（每个 school 目录各做一次）
--------------------------------------------------------------------------------

必须先让 exe 记住账号，否则定时跑只会打印「未登录」：

  "<你的目录>\运动规划.exe" login --user 手机号 --pass 密码 --remember

（或者在 GUI 里登录时勾选「记住密码」，效果一样。会话失效时脚本会用它自动重登。）


二、注册（示例：湖南包，每天 07:30 触发，跑 2.0km / 6'30"/km，出发时刻当天 07:32）
--------------------------------------------------------------------------------

  cd "D:\运动世界\定时任务"
  powershell -ExecutionPolicy Bypass -File .\注册每日任务.ps1 `
      -At 07:30 `
      -Exe "D:\运动世界\湖南石油化工职业技术学院-源码\dist\运动规划-TLS修复版-20261015\运动规划.exe" `
      -Dist 2.0 -Pace 390 -When 07:32 -Name "运动规划-湖南"

参数：

  -At   07:30   计划任务触发时刻（电脑时间的几点）
  -Exe          exe 全路径（决定用哪个学校/哪个账号的数据）
  -Dist 2.0     公里数
  -Pace 390     配速，秒/公里（390 = 6'30"）
  -When 07:32   记录里的出发时刻 HH:MM（要落在学校允许时段内）；
                填数字（例如 90）表示「90 分钟前出发」
  -Name         任务名，不填则按目录自动起名
  -Wake         到点唤醒电脑（还要在「电源选项」里允许唤醒定时器）
  -DryRun       只打印不真跑（用来验证链路，不会产生记录）

多开几个学校：同一个脚本多跑几遍，换 -Exe / -Name / -At 即可。


三、验证与查看
--------------------------------------------------------------------------------

  验证链路（不提交记录）：
    powershell -ExecutionPolicy Bypass -File .\注册每日任务.ps1 -At 07:30 `
        -Exe "...\运动规划.exe" -DryRun -Name "测试-链路"
    Start-ScheduledTask -TaskName "测试-链路"

  立刻真跑一次：
    Start-ScheduledTask -TaskName "运动规划-湖南"

  看日志：
    Get-Content "D:\运动世界\定时任务\logs\$(Get-Date -Format yyyyMMdd).log" -Tail 30

  看任务状态：
    Get-ScheduledTask -TaskName "运动规划-湖南" | Get-ScheduledTaskInfo

  删除任务：
    powershell -ExecutionPolicy Bypass -File .\注册每日任务.ps1 -Remove -Exe "..." -At 00:00 -Name "运动规划-湖南"
    （-Remove 只看 -Name，其余参数随便填）


四、行为细节
--------------------------------------------------------------------------------

- 错过补跑：任务带 StartWhenAvailable —— 关机/睡眠错过触发，开机后会尽快补跑一次。
- 同一天只跑一次：日志里出现 "exit 0" 就跳过当天后续运行（避免补跑 + 正常触发撞车）。
  确实要再跑一次：手动执行 定时跑步.cmd "<exe>" --force
- 电脑要开着并处于登录状态（计划任务默认「仅在用户登录时运行」）。想彻底不怕忘记，
  就把它放到一台常开的 Windows 机器上（见下）。
- 想手动试一下脚本（不注册任务）：
    定时跑步.cmd "<exe 路径>" 2.0 390 07:30 --test   （只打印）
    定时跑步.cmd "<exe 路径>" 2.0 390 07:30          （真跑）


五、挂云端
--------------------------------------------------------------------------------

- Windows 云主机 / 云电脑（最省事，今天就能用）：
  整个 exe 目录拷过去，一起带上 accounts.json / config.json / identity.json
  （identity.json 是设备身份，不拷会变成新设备，可能触发设备风险），
  在云主机上 `login --remember` 一次，再用本目录的脚本注册计划任务。
- Linux / 青龙面板：需要一份 Linux 版的 CLI 构建（源码支持 --no-default-features
  的纯命令行版），本机只装了 Windows 编译目标且处于离线，做不了；
  要出 Linux 版需要在一台能联网的机器上编译，之后青龙里 cron 调
    ./运动规划 login --user .. --pass .. --remember   （一次）
    ./运动规划 run --dist 2.0 --pace 390 --ago 90     （定时）
  项目文档里本来就写了「青龙定时任务」这条路线，需要的话我再给你出 Linux 包。


六、已知限制
--------------------------------------------------------------------------------

- 朋友版只支持「今天」跑步（--days-ago 已移除），所以只能定时，不能补历史天数。
- 日志会一直累积，按天一个文件；不需要的话手动删 logs 目录即可。
