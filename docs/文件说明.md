# 仓库文件说明

这份文件逐个说明仓库里每个目录、每个文件是干什么用的，方便你和同学快速找到东西。

## 根目录

| 文件 / 目录 | 作用 |
| --- | --- |
| `README.md` | 项目总说明：功能介绍、自助生成入口、运行环境、双人协作规则 |
| `提示词.md` | 交给 AI 自助生成程序的提示词（编译 + 登录 + 识别学校位置） |
| `LICENSE` | 开源许可证（CC BY-NC 4.0，禁止商用） |
| `.gitignore` | 指定哪些文件不进入仓库 |
| `Cargo.toml` / `Cargo.lock` | Rust 工程配置与依赖版本锁定 |
| `src/` | 程序全部 Rust 源码（界面、协议、轨迹生成、命令行） |
| `crates/route-planner/` | 轨迹规划子模块，独立编译的 Rust 库 |
| `assets/` | 程序内置资源，目前是中文字体文件 |
| `android/` | Android 版本打包相关的脚本与配置 |
| `vendor/winit-0.30.13/` | 本地修改过的 winit 窗口库源码 |
| `.github/workflows/` | GitHub 自动构建：推 tag 自动出各平台安装包 |
| `docs/` | 文档与图片，详见下文 |
| `data/` | 路网数据，详见下文 |
| `tools/` | 辅助工具，详见下文 |

## 成品包（已不再入库）

早期按学校/地区打包的成品（如天津版、辽源版）**不再放进仓库**，需要时在 git 历史里查。
现在的模式是「源码 + 提示词」：自己编译生成自己学校的程序，见 [提示词.md](../提示词.md)。
打包输出目录（`dist/`、`NekoSportsWorldTool-win-x64/`、各学校源码副本）一直在 `.gitignore` 里，不会上传。

## 不会上传的内容

下面这些文件只在你本地存在，`.gitignore` 已把它们排除，不会进入 GitHub：

| 文件 / 目录 | 说明 |
| --- | --- |
| `_keybackup/`、`*.key` | 私钥备份，绝对不能上传 |
| `proxies.txt` | 代理列表 |
| `target/`、`dist/` | 编译产物 |
| `*.exe`、`*.zip` | 打包出来的程序和导出包 |
| `history_tracks/`、`records_raw.json`、`obs_*.json` | 跑步记录等本地运行数据 |
| `.env`、`*.secret`、`*.log` | 环境变量、密钥、日志 |
