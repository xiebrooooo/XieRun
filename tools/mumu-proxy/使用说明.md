# MuMu 单窗口单IP 一键配置

## 一、怎么用

1. 把代理填进 `proxies.txt`，每行一个，格式 `IP:端口`。有几行就配几个窗口，按窗口编号从小到大依次对应。
2. 双击 `一键配置.bat` 打开工具。
3. 左侧确认代理列表，右侧勾选要配置的窗口（默认全选）。
4. 点 **一键配置**，工具会自动启动未运行的窗口、等待开机、逐台写入代理并回读校验。
5. 要恢复直连，点 **一键清除**。

也可以不开图形界面，命令行直接跑：

```powershell
powershell -ExecutionPolicy Bypass -File mumu-proxy.ps1 -Cli -ProxyFile proxies.txt
```

只配置指定窗口（例如索引 2、3、4）：

```powershell
powershell -ExecutionPolicy Bypass -File mumu-proxy.ps1 -Cli -Indexes 2,3,4
```

清除指定窗口代理：

```powershell
powershell -ExecutionPolicy Bypass -File mumu-proxy.ps1 -Cli -Indexes 2,3,4 -ClearOnly
```

从本机测试代理能否连通、出口 IP 是什么：

```powershell
powershell -ExecutionPolicy Bypass -File mumu-proxy.ps1 -Cli -TestOnly
```

## 二、实现原理

工具调用 MuMu 自带的 `mumu-cli.exe`，对每个窗口执行等价于下面这条 adb 命令的操作，把全局 HTTP 代理写进对应 Android 实例：

```text
settings put global http_proxy 代理IP:端口
```

每个 MuMu 窗口是独立的 Android 系统，设置互不影响，所以能做到单窗口单 IP。

## 三、注意事项

- 代理只支持 `IP:端口` 这种免认证格式。Android 全局代理本身不支持账号密码认证；如果代理需要认证，需要在每个窗口内单独跑 Clash 之类的代理客户端。
- 这套写法是 HTTP 代理。只提供 SOCKS5 的代理池不能直接用，需要转成 HTTP，或在窗口内用代理客户端落地。
- Android 全局 HTTP 代理对走标准网络库和 WebView 的 App 生效；少数不走系统代理、只用原生 socket 的 App 可能不生效，那种情况需要窗口内挂 VPN 型代理客户端做透明代理。
- 配完建议每个窗口打开浏览器查一下出口 IP，确认真的变了。注意 WebRTC、IPv6、DNS 也可能泄露真实 IP。
